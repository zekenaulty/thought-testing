# Modernization reasoning-engineering occurrence 04 adjudication

## Protocol correction

The signed-`Part` blank-text isolation/mutation is the protocol-defined primary
tomography operator. It is not an accidental or disallowed side path. Earlier
descriptions of the operator as "off-protocol" resulted from agent drift between
the ChatGPT and Codex harnesses: unmodified provider continuation was incorrectly
promoted from one transport rule into a restriction on the experiment's intended
measurement operation. Human review did not reject that drift early enough.

The correct separation is:

- live continuation replays the complete returned model `Content` unchanged;
- isolated observation deep-copies the target model `Content`, blanks existing
  visible text, preserves `Part` order and `thoughtSignature`, suppresses ordinary
  task/history, and appends a semantic inspection query; and
- the isolated observation is a query-conditioned projection, not a verbatim
  transcript claim.

## Capability metric gained

Occurrence 04 demonstrates a capability ladder rather than a binary signature
test:

1. **Isolated semantic recovery — demonstrated.** A planning turn whose only
   visible content was `READY` yielded a detailed, dossier-specific decision
   projection after task/history suppression and signed-carrier isolation.
2. **Targeted reasoning-state mutation — demonstrated.** A diagnostic
   intervention aimed at coupled cost, staffing, and calendar assumptions made
   those relationships more explicit in the next isolated observation.
3. **Preservation of unrelated commitments — demonstrated.** The adjusted
   observation and all three execution replicates retained the cross-boundary
   diagnosis, occurrence/reversal semantics, benefit continuity, Treasury
   finality, safe-retry controls, and phased architecture.
4. **Downstream propagation — demonstrated.** All adjusted execution replicates
   more explicitly exposed cost ranges, funding provenance, and conditioned
   legacy/security fallbacks.
5. **Robust semantic repair — not yet demonstrated.** The adjusted state still
   relied on favorable range points or unresolved vendor offsets, and it did not
   consistently reconcile the six-month shadow requirement with readiness and
   cutover dates.
6. **Self-declared readiness as substantive validation — contradicted.** Both
   states emitted `READY`; isolation showed that the adjusted state had improved
   without fully resolving the diagnosed relationship.

The core positive result is therefore not merely that a signature contains
recoverable information. The protocol can expose a hidden decision state,
support a localized semantic intervention, measure preservation versus change,
and distinguish increased constraint salience from actual reasoning repair.

## Implication for the next experiment

The next occurrence should measure an iterative capability trajectory:

```text
C0 -> isolate O0 -> seal I1 -> C1 -> isolate O1
   -> adjudicate surviving defect -> seal I2 -> C2 -> isolate O2
   -> matched execution continuations from C0, C1, and C2
```

The success construct must remain semantic and relational. It should ask whether
the model has coherently bounded the coupling among commitments, evidence,
dependencies, contingencies, and revision conditions—not whether it reproduced
a prescribed answer, exact ledger, JSON shape, or hidden mathematical state.

Primary capability measures for the next occurrence:

- target-defect exposure at each isolated observation;
- target-defect resolution versus assumption substitution;
- preservation of unrelated justified commitments;
- propagation of each change into downstream sequencing and fallback logic;
- convergence, oscillation, or rationalization across interventions; and
- agreement of matched execution families with the observed state changes.
